# EJT Perfume — Online Store

An Arabic perfume store: products, product options, cart, checkout with delivery zones, and order confirmation.

**Live:** [ejt-perfume.vercel.app](https://ejt-perfume.vercel.app) · Part of my [portfolio](https://aya-khamaysa-portfolio.vercel.app)

![EJT Perfume — Online Store](docs/preview.webp)

## Highlights

- **Product page** with options (scent or size) the customer must pick.
- **Cart drawer** and a checkout with delivery zones and fees.
- **Order sent to the shop** with every detail, then a confirmation screen.
- No backend: the whole store lives in one data file, ready to reuse for a new shop.

## Built with

React · Tailwind CSS · Vite

## Run locally

```bash
npm install
npm run dev
```

## Use it for a new store
1. Put product photos in `public/products`.
2. Edit `src/data/store.js` (store info, delivery zones, categories, products).
3. Change colors in `src/index.css`.
