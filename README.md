# EJT Perfume — Store Demo

Demo online store for pitching: products, product page with options, cart, checkout with delivery zones, and order confirmation.
No backend: everything lives in `src/data/store.js`. Built with React, Vite and Tailwind CSS by One Click.

## Run
```bash
npm install
npm run dev
```

## For a new store
1. Put product photos in `public/products`
2. Edit `src/data/store.js` (store info, delivery zones, categories, products)
3. Change colors in `src/index.css`
4. `npm run build` and upload the `dist` folder to Vercel
